# Материалы встреч

Положите сюда протоколы, заметки, готовые расшифровки и ответы интервью.
Для каждой встречи удобно создать папку с датой и темой, например
`2026-10-07 Закупки`. Аудио и видео требуют отдельно доступной обработки;
если её нет, передайте расшифровку.

Попросите: «Проанализируй материалы встречи в папке …: выдели решения,
требования и открытые вопросы». Если материалы относятся к конкретной задаче,
укажите её ссылку; придумывать номер заранее не нужно.

Агент принимает выбранные файлы через intake. Само размещение не запускает анализ.
