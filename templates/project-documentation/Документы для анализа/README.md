# Документы для анализа

Положите сюда регламенты, инструкции, схемы процессов, существующие ФС,
описания систем и другие документы, которые агент должен изучить.
Материалы одной темы удобно собрать в подпапку с понятным названием.

Попросите: «Изучи документы из папки … и опиши процесс …» или
«Сравни эти две версии и перечисли изменения». Укажите цель анализа и нужные
файлы; агент проверит поддержку форматов и примет выбранные материалы.

Если это запись встречи, шаблон или реестр, используйте соответствующий
раздел. Исходники XML/BSL конфигурации и расширения подключаются отдельно
при настройке Flow1C, а не копируются в репозиторий документации.
