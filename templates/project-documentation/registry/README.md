# Служебные данные реестра

Flow1C хранит здесь принятый Excel в `source/requirements.xlsx`, индексы
и отчёт импорта. Обновление выполняется импортом исходного Excel через агента.

Исходные версии складывайте в [Реестр процессов и требований](<{{documentation-prefix}}Реестр процессов и требований/>).
