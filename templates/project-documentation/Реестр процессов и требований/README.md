# Реестр процессов и требований

Положите сюда исходный Excel-файл реестра. Сохраняйте разные версии отдельными
файлами с понятными именами; при запросе укажите нужную версию.

Попросите: «Импортируй реестр процессов и требований из файла …».
Агент проверит структуру таблицы, выполнит импорт и покажет его результат.
Если структура не подходит, сообщит, что нужно исправить.

Папка `registry` содержит принятый снимок и индексы Flow1C. Не редактируйте
их вручную: сначала измените исходный Excel, затем попросите новый импорт.
Размещение файла в этой папке само по себе не заменяет действующий реестр.
