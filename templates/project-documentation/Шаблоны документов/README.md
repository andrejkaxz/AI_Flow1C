# Шаблоны документов

Положите сюда исходные шаблоны DOCX/Markdown и заполненные образцы: ФС, ТЗ,
протокол встречи, инструкция пользователя и другие типы из каталога продукта.
Назовите файл так, чтобы было понятно его назначение и версия.

Попросите: «Добавь этот шаблон ТЗ в библиотеку проекта». Укажите, где шаблон,
а где заполненный образец. Агент проверит структуру и уточнит правила заполнения.

Файлы в этой папке — входные материалы. Для использования шаблона агент должен
принять его в библиотеку; папку `document-templates` вручную заполнять не нужно.
Добавление файла не делает его утверждённым шаблоном автоматически.
