# Входные данные

В этой папке хранится снимок требований, относящийся только к данной задаче. Исходный идентификатор пользователя хранится в manifest, а имя каталога является безопасным slug.

Материалы встреч, переписку, выжимки и транскрибации добавляйте в `meetings/`. Не помещайте сюда пароли, токены и другие секреты.

Агент принимает приложенные в чат файлы или указанный пользователем каталог через контролируемый intake. Материалы встреч сохраняются пакетами в `meetings/<intake-id>/`, остальные документы — в `attachments/<intake-id>/`, извлечённый текст — в `derived/<intake-id>/`. `artifacts.json` содержит хеши и трассировку принятых материалов.
