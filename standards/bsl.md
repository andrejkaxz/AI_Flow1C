# Базовые правила BSL

Этот файл фиксирует проектный baseline. При ревью дополнять его актуальными нормами ИТС/v8std и диагностикой BSL Language Server.

Автоматическая проверка запускается командой `PowerShell -ExecutionPolicy Bypass -File .\scripts\analyze-bsl.ps1`. Отчёт BSL LS является отдельным источником доказательств; функциональное соответствие проверяется по утверждённой ФС и требованиям.

- Имена процедур, функций, параметров и переменных: кириллица, `ВерблюжийРегистр`.
- Отступ: табуляция. Одна инструкция на строку.
- Модули группируются через `#Область`/`#КонецОбласти`.
- Экспортируется только реально внешний API. Экспортные функции документируются.
- Исключения не проглатываются: ошибка логируется или преобразуется в явный результат.
- Каждый внешний HTTP/веб-сервисный вызов имеет собственную обработку ошибок.
- Данные из внешних API, LLM и ввода пользователя валидируются до использования.
- Циклы с неопределённым условием имеют лимит и явную обработку его исчерпания.
- При конкурентной записи проверяются транзакции и управляемые блокировки.
- Тяжёлые вычисления, запросы и запись выполняются на сервере. Серверные вызовы в циклах батчируются.
- Точные имена типов, метаданных, реквизитов и методов проверяются по исходникам.
