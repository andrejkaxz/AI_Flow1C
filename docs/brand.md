# Логотип и слоган Flow1C

**Анализ — легко. Процесс — в удовольствие.**

![AI Flow1C — логотип с бабочкой](assets/flow1c-logo.svg)

Бабочка из четырёх плавных крыльев передаёт лёгкость управления и перерождение
процессов. Монохромный знак сопровождает надпись **AI Flow1C**. Название продукта
в документации и командах остаётся **Flow1C**.

- [Исходный логотип PNG с прозрачным фоном](assets/flow1c-logo.png) — 2172 × 724 px.
- [Логотип SVG на светлой подложке](assets/flow1c-logo.svg) — для README и страниц
  документации в светлой и тёмной теме. SVG встраивает исходный PNG;
  это контейнер для отображения, а не векторизация знака.

Исходный логотип создан встроенным ImageGen. Форма знака и надпись сохранены;
слоган размещается отдельным текстом, чтобы оставаться читаемым и доступным.
