# Оформление шаблонов Excel

Flow1C применяет визуальное оформление книги-образца к выбранным диапазонам
копий XLS (Excel 97–2003) и XLSX. Результат сохраняется в исходном формате.
Поддерживаются шрифты, заливки, границы, выравнивание и по выбору высота строк
и ширина столбцов. Исходник определяет листы, колонки, значения, формулы,
числовые форматы и правила проверки данных. При назначении произвольного цвета
на XLS действуют ограничения палитры Excel 97–2003.

## Запуск

Нужны Windows, настольный Microsoft Excel с доступной COM-автоматизацией и
настроенный `documentation_path`. Разрешены обычные XLS и XLSX внутри этой папки.
Форматтер открывает временные копии, отключает VBA и обновление внешних ссылок.
Зашифрованные книги и обнаруженные макросы Excel 4.0/VBA отклоняются до открытия.

Откройте `agent-begin --json-stdin` / `flow1c_begin` с вложенным предложением
маршрута `operation=workbook-format`, `mode=draft`. Полученный `gate_id`
используйте для всех книг запроса. Для источника `attachment` укажите имя
выбранной книги или папки в `selector`.

- **Codex** вызывает `scripts/flow1c.py workbook-format --json-stdin`.
- **OpenCode** вызывает `flow1c_workbook` с полями `gate_id`, `action` и
  `request_json`. Последнее поле содержит JSON-строку значения `request` из
  следующих примеров.

```json
{"gate_id":"<gate>","action":"list","request":{"folder":"Migration"}}
```

```json
{"gate_id":"<gate>","action":"inspect","request":{"source":"Migration/Stores.xls"}}
```

```json
{
  "gate_id": "<gate>",
  "action": "write",
  "request": {
    "source": "Migration/Stores.xls",
    "reference": "Examples/Example.xlsx",
    "mappings": [
      {
        "target_sheet": "Load",
        "target_range": "B11:K11",
        "reference_sheet": "Example",
        "reference_range": "B3",
        "row_heights": true
      }
    ]
  }
}
```

`list` показывает до 100 файлов непосредственно в выбранной папке. `inspect`
показывает листы, используемые диапазоны и текст первых 14 строк и 12 столбцов.
Адреса в карте задаются в A1 с точными именами листов. Размеры диапазонов
должны совпадать по каждой оси. Одна строка или один столбец эталона
могут повторяться по целевому диапазону. Параметры `row_heights` и
`column_widths` по умолчанию выключены. Поздние правила переопределяют ранние в
пересекающихся диапазонах. Лимиты на одну книгу: 24 МиБ, 40 правил, 4096
целевых ячеек. Проверка ограничена 250 000 ячейками используемой области на
лист и 4096 ячейками на область проверки данных.

Для повторного использования сохраните JSON с полями `schema_version: 1`,
`reference` и `mappings` внутри документации. Во входе `write` передайте
`{"source":"Migration/Stores.xls","profile":"Examples/Style.json"}` вместо
отдельных `reference` и `mappings`. Относительные пути считаются от корня
документации проекта.

## Результат

`write` открывает сохранённую копию и сравнивает листы, непустые ячейки,
формулы, именованные диапазоны и правила проверки данных. Flow1C сохраняет
копию в `workbooks/` текущего черновика и возвращает её абсолютный путь,
отпечатки книги и эталона и карту диапазонов. Повтор неизменившегося запроса
возвращает ту же проверенную копию. При изменении результата Flow1C сообщает
об ошибке, сохраняя файл. Для нескольких книг повторите `write` на том же gate.
После проверки памяти завершите запрос через `agent-complete` /
`flow1c_complete` без указания `output`. В ответе будут пути всех копий.

`layout_review=UNVERIFIED` оставляет визуальную оценку за просмотром в Excel.
Совместимость конкретного загрузчика 1С проверяется отдельно.
